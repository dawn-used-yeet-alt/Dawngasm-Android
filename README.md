# Dawngasm (Android)

An Android app to browse, download, and stream audios from r/gonewildaudio and adjacent subreddits.

> [!NOTE]
>
> Dawngasm is intended for streaming and downloading audio that you own or have permission to access and use. Please respect the rights of content creators and applicable local laws.

# Something that you should probably know. 

The app doesn't connect to Reddit directly.

Reddit has made it pretty much impossible for you (yes you) to be able to make an api client. 99% of people would probably not be use the app if it was made that way.

Instead, Dawngasm uses my own ["database"](https://dawngasm.dawnusedyeet.workers.dev/) to get the data from.

# Privacy

I don't collect any(yes any) user data, and I don't want or intend to.

The only tracking you might encounter comes from third-party services, such as Cloudflare or the audio hosting platforms you connect to. Which I can't realistically do nothing about.
